# Acts Lesson Gospel App

Interactive mobile-first Bible lesson app for:

**Module 1 — Lesson 2**  
**Acts Part 1 — Salvation & the Gospel of Christ**

Theme: **The Apostolic Gospel — Death, Burial, Resurrection**  
Call to action: **Obey the Gospel of Jesus Christ**

## Run Locally

```sh
npm install
npm run dev
```

Then open the local URL printed by Vite, usually:

```text
http://localhost:5173
```

## Features

- Mobile-first React lesson experience
- Expandable teaching sections and Scripture cards
- Progress tracking with localStorage
- Reflection boxes saved on the device
- Reset confirmation for progress and reflections
- Print-only one-page lesson summary
